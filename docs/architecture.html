Drishti Workbench — Architecture

Zero-Trust Air-Gap

  • • No cloud LLM client exists in the codebase — not blocked, never built
  • • ChromaDB's default telemetry + auto-embedder found and disabled by hand
  • • Three independent proofs: app counter, OS socket table, kernel firewall
  • • Live during every demo: 0 external calls, climbing internal count

Agentic Pipeline

  • • Regex router picks an agent with zero LLM cost per request
  • • Reasoning · Coder · Vision · Document — each its own local model
  • • One tool registry — the only route to any capability, fully logged
  • • Depth-limited delegation between agents, no runaway loops

Tamper-Evident Everything

  • • SHA-256 hash-chained audit trail — edit one row, break every row after
  • • RAG grounded in local documents, citations shown, never fabricated
  • • Sandboxed code execution verified with real failed syscalls, not flags
  • • Persistent threads + structurally RAG-isolated user memory
